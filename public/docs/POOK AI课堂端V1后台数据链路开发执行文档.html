POOK AI课堂端V1后台数据链路开发执行文档

这份文档面向研发。目标是先跑通正式上线最小闭环，不把学生个人档案、多老师权限和复杂报表提前塞进V1。

阅读说明 先看结论，再看细节。

这份文档围绕《POOK AI课堂端V1后台数据链路开发执行文档》展开，重点不是堆功能，而是把模糊讨论收口成可判断、可协作、可开发或可验收的产品依据。

  • 简单摘要：先确认本文解决的问题、核心结论和适用版本。
  • PM价值：把真实场景、用户问题、业务规则和执行边界讲清楚，减少团队理解偏差。
  • 使用方式：老板看结论和风险，设计看页面目标，开发看规则和验收口径。

1. 开发里程碑

  1. 账号登录与机构小队拉取。
  2. 登录后选择小队，并在前端全局绑定当前小队。
  3. 课程配置表接入，首页展示课程地图和解锁状态。
  4. 完成课程后生成课堂完成记录和成长卡。
  5. 奖励入账：星星、经验、宝石、纪念卡。
  6. 更新课程解锁状态和上次闯关耗时。
  7. 成长中心按三个视图读取当前小队数据：卡片收集册、成长记录册、小队总览。
  8. 教师验证后进入商城，完成兑换和扣减宝石。
  9. 设备测试、设置页和错误态补齐。
  10. 完整链路联调验收。

2. 模块任务拆解

账号与机构

  • 实现母账号登录接口，返回token、机构信息和账号状态。
  • 一个机构只对应一个母账号；V1不做多老师账号。
  • 登录成功后前端必须进入小队选择页，不允许默认使用1号小队。

小队

  • 后端返回当前机构下的小队列表，数量不固定。
  • 前端选择小队后写入全局状态，并用于后续所有接口请求。
  • 所有奖励、成长卡、课程进度、兑换记录都必须绑定team_id。

课程配置与解锁

  • 后端提供课程配置接口，字段包含主题、难度、顺序、资源、问答、积木、奖励。
  • 后端提供当前小队课程解锁状态接口。
  • 前端课程小球展示：锁定/已解锁/已完成/上次闯关耗时。

课堂完成记录

  • 点击课程节点进入课程时，即视为开始上课，并记录started_at。
  • 领取完成本节课全部上课奖励后，视为课程结束，并记录finished_at和duration_seconds。
  • V1只持久化课程级完成记录，不持久化每个环节过程状态。

奖励与成长

  • 课程完成后后端统一计算并写入星星、经验、宝石。
  • 首次完成某节课：发放纪念卡、经验和100宝石。
  • 同一小队重复完成同一课程：不重复发放纪念卡和经验，只发放10宝石。
  • 纪念卡按team_id + course_id去重；已拥有时不重复创建收藏关系。
  • 成长卡记录保存到team_id下，成长中心按小队查询。
  • 成长中心不再是一个混合列表，拆成三个数据视图：卡片收集册、成长记录册、小队总览。
  • 卡片收集册按课程主题分组展示纪念卡，未获得课程也需要返回占位状态，方便前端展示收集进度。
  • 成长记录册按课堂完成记录展示每堂课的成长卡/风采内容，数据来源是lesson_record + growth_card_record。
  • 小队总览只展示聚合数据，例如纪念卡数、星星、经验、宝石、完成课程数、最近表现。

商城兑换

  • 前端进入兑换前保留算术验证。
  • 兑换接口必须校验当前小队宝石余额。
  • 每个商品对同一小队仅限购买一次，不能重复购买。
  • 兑换成功后扣减宝石并生成兑换记录。
  • 兑换操作完成后，前端将对应商品兑换按钮替换为灰色“已售罄”。
  • V1不需要做全局库存扣减；“已售罄”表示当前小队已兑换该商品。

隐私与数据授权

  • 授权说明入口放在“我的-隐私”。
  • 前端不展示上课照片，但后台可保存照片或动作数据存储key，用于课程过程分析。
  • 隐私文案核心口径：课堂数据仅限本次课程和教学分析使用，已进行安全加密，防止隐私泄露。
“为了帮助POKI更好地理解课堂互动情况，我们会在课程过程中采集必要的画面与动作数据。相关数据仅用于本次课程识别、课堂效果分析和产品体验优化，不会在成长中心公开展示。所有数据都会进行安全加密处理，严格限制访问权限，防止隐私泄露，请放心使用。”

team_id course_id unlock_status unlocked_at completed_at last_duration_seconds best_duration_seconds attempt_count has_granted_first_reward

lesson_record

lesson_record_id team_id course_id started_at finished_at duration_seconds completion_status photo_storage_key motion_data_key

growth_card_record

growth_card_id team_id course_id lesson_record_id summary stars_awarded xp_awarded gems_awarded is_first_completion created_at

card_catalog

card_id course_id theme_id title visual_key badge_name card_order status

card_collection

team_id card_id course_id earned_at is_flash_card source_lesson_record_id last_upgraded_at

growth_center_view

不一定需要真实建表，可以由后端聚合返回。至少包含三块：overview、card_album、growth_records。

  • overview：小队星星、经验、宝石、完成课程数、纪念卡数、最近表现。
  • card_album：按theme_id返回主题、课程卡片、owned状态、is_flash_card状态、收集进度。
  • growth_records：按lesson_record返回课堂成长卡、课程名、主题、完成时间、奖励、能力标签、风采摘要。

shop_item / shop_exchange

item_id name cost_gems status / exchange_id team_id item_id cost_gems exchange_status exchanged_at

4. V1接口清单

  1. POST /auth/login：母账号登录。
  2. GET /institutions/me：获取当前机构信息。
  3. GET /teams：获取当前机构下小队列表。
  4. GET /teams/{teamId}/dashboard：获取小队首页所需聚合数据。
  5. GET /courses：获取课程配置列表。
  6. GET /teams/{teamId}/course-progress：获取小队课程解锁状态。
  7. POST /lesson-records/start：创建课堂开始记录。
  8. POST /lesson-records/{recordId}/complete：完成课程并触发奖励、成长卡、解锁。
  9. GET /teams/{teamId}/growth-center：查询成长中心聚合数据，包含overview、card_album、growth_records。
  10. GET /teams/{teamId}/growth-cards：查询小队成长卡记录，用于成长记录册。
  11. GET /teams/{teamId}/cards：查询小队纪念卡收藏，用于卡片收集册。
  12. GET /teams/{teamId}/card-album?themeId=xxx：按主题查询卡片收集册，返回已获得和未获得卡片的展示状态。
  13. GET /shop/items：查询商城商品。
  14. POST /shop/exchanges：兑换商品，校验当前小队是否已兑换，扣减宝石并生成记录。
  15. GET /teams/{teamId}/shop-exchanges：查询小队兑换记录。

5. 验收标准

  • 登录后不能直接进入首页，必须先选择小队。
  • 不同母账号可配置不同数量小队。
  • 选中小队后，首页、成长、商城、奖励都读取同一个team_id。
  • 只解锁当前小队可上的课程，未解锁课程不可进入。
  • 完成一节课后，生成lesson_record和growth_card_record。
  • 点进课程即记录课程开始时间，领取完上课奖励后记录课程结束时间。
  • 首次完成课程时，星星、经验、100宝石正确累加到当前小队。
  • 同一小队重复完成同一课程时，不重复发放纪念卡和经验，只发放10宝石。
  • 纪念卡按小队和课程去重，重复课程不重复获得。
  • 课程完成后正确解锁下一节课或下一难度梯度。
  • 课程小球展示上次闯关耗时。
  • 商城兑换必须通过教师验证，兑换成功后扣减宝石并生成记录。
  • 同一小队已兑换过的商品按钮展示为灰色“已售罄”，且不可重复兑换。
  • 成长中心默认进入卡片收集册，且只展示当前小队的数据。
  • 卡片收集册支持按课程主题切换，能展示每个主题下已收集/未收集卡片和收集进度。
  • 成长记录册能看到当前小队每堂课的成长卡/风采记录。
  • 小队总览单独展示聚合数据，不挤占卡片收集册和成长记录册。
  • 照片和动作数据不在前端展示，但后端可保存存储key。
  • “我的-隐私”展示课堂数据采集与安全加密说明。

6. 已确认口径

  • 课程开始时间：点进课程即开始上课。
  • 课程结束时间：领取完成上课奖励后，算课程结束。
  • 重复完成课程：不重复发放卡片和经验；宝石重复发放，但首次100宝石，重复10宝石。
  • 商城兑换：每个商品对同一小队仅限购买一次，不需要做全局库存扣减。
  • 兑换状态：兑换完成后按钮替换为灰色“已售罄”。
  • 隐私入口：写在“我的-隐私”，说明课堂数据仅限本次课程和教学分析使用，并进行安全加密。
