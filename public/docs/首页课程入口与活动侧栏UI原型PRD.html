PRD / 首页 UI 原型

首页课程入口与活动侧栏 UI 原型 PRD

这版 PRD 不改首页主体逻辑，只把 UI 结构说清楚，让设计师能直接出图，开发能直接拆组件。

阅读说明 先看结论，再看细节。

这份文档围绕《首页课程入口与活动侧栏 UI 原型 PRD》展开，重点不是堆功能，而是把模糊讨论收口成可判断、可协作、可开发或可验收的产品依据。

  • 简单摘要：先确认本文解决的问题、核心结论和适用版本。
  • PM价值：把真实场景、用户问题、业务规则和执行边界讲清楚，减少团队理解偏差。
  • 使用方式：老板看结论和风险，设计看页面目标，开发看规则和验收口径。

一句话结论

首页不是信息门户，而是上课入口。页面中心只做课程选择；右侧小球只收纳课程外内容；点击小球后弹出活动内容面板，而不是跳转到另一个导航页。

主任务

让小朋友和老师一眼知道：今天从哪个课程节点开始。

次任务

保留线下活动、产品理念、风采展馆，但不抢主舞台。合作机构入口删除，因为进入 App 的老师默认已经来自合作机构。

不做

不把首页做成底部导航的重复入口，也不把品牌内容平铺到主区域。

视觉风格

推荐风格：POKI 玩具盒式课堂 UI

这个风格最适合当前产品的核心客群：4-6 岁儿童 + 幼儿园保育老师。

  • 给孩子看：优先用大图形、大色块、圆形按钮、少量短文字。
  • 给老师看：保留清晰标题、状态和可操作入口，避免需要培训才能理解。
  • 给后续页面复用：课程外页面都可以沿用“大容器 + 小圆球 + 抽屉面板 + 短文案”的结构。

风格关键词：像玩具、像课堂、像任务地图，不像后台、不像官网、不像普通 App 首页。

页面结构

首页保持一个稳定的五层结构，从外到内如下：

  1. 全局顶栏：保留账号、宝石、标题等全局状态，不参与本次重构。
  2. 首页大画布：承载本页主要内容，是一个完整的大圆角容器。
  3. 课程主舞台：大画布内部左中区域，展示主题书签和课程节点。
  4. 右侧活动小球：固定在大画布右侧，收纳课程外信息。
  5. 活动抽屉面板：点击小球后从右侧弹出，展示具体活动内容。

线框关系

可以按这个结构画低保真：

A. 左侧主题书签

竖向排列。每个书签用图形表达主题，文字只做辅助。选中态向右突出。

B. 中间课程地图

占据最大面积。展示当前主题下的课程节点，默认只突出当前可学习节点。

C. 右侧活动小球

竖向集中排列。它们是次级入口，不进入主舞台。

D. 右侧抽屉面板

只在点击小球后出现，覆盖在大画布右侧，不改变主舞台结构。

区域说明

1. 首页大画布

  • 作用：承载首页全部内容，形成一个“课堂选择台”。
  • 视觉：大圆角、深色底、彩色光感，但不能盖过课程节点。
  • 边界：大画布内部元素不能和底部导航、顶栏重叠。

2. POKI 引导区

  • 位置：主舞台左上方。
  • 内容：POKI 图标 + 一句短提示。
  • 文案建议：点亮第一关 / 跟 POKI 开始。
  • 限制：不写产品解释，不写 AI 思考过程语。

3. 主题书签区

  • 位置：课程主舞台左侧。
  • 内容：生命科学、自然科学、工程科学、社会人文。
  • 形态：竖向书签，不改成横向 Tab。
  • 表达：优先使用图形或图片，文字只保留 2-4 个字。
  • 选中态：书签向右突出，颜色更亮，像被抽出来。

4. 课程节点地图区

  • 位置：课程主舞台中央。
  • 内容：当前主题下的 5 个课程节点。
  • 默认：只解锁最新可学习节点，其它节点弱化。
  • 引导：当前可学习节点上方展示 POKI 提示。
  • 目标：让孩子知道“点亮这个”，老师知道“从这里开始”。

5. 活动小球区

  • 位置：大画布最右侧，垂直居中。
  • 内容：线下活动、产品理念、风采展馆。
  • 形态：圆形按钮，图标大，文字小。
  • 收起：最右侧保留“》/《”按钮。
  • 注意：小球不是底部导航，不放课程、成长、商城、教师功能这些导航页复刻。

6. 活动抽屉面板

  • 触发：点击任意活动小球。
  • 位置：从右侧弹出，位于活动小球左侧或覆盖右侧画布区域。
  • 内容结构：大图标 / 小标签 / 标题 / 一句说明 / 3 条要点。
  • 关闭：右上角关闭按钮；收起小球时同步关闭。
  • 原则：它是活动内容界面，不是导航菜单。

页面状态

默认状态

主舞台展示课程地图；右侧活动小球展开；没有活动抽屉。

小球收起状态

右侧只保留一个展开按钮，主舞台视觉更干净。

活动打开状态

被点击的小球高亮；右侧弹出活动抽屉；课程地图仍留在背景中。

课程节点点击状态

点击已解锁节点进入课程；点击未解锁节点弹 toast，提示先完成当前节点。

组件清单

  1. HomeCanvas：首页大画布容器。
  2. PokiHomeGuide：POKI 首页引导区。
  3. ThemeBookmarkRail：左侧主题书签栏。
  4. LessonNodeMap：课程节点地图。
  5. ActivityBubbleRail：右侧活动小球组。
  6. ActivityDrawer：活动抽屉面板。
  7. ActivityDrawerCard：抽屉中的内容卡片结构。

内容规则

活动小球内容

  • 线下活动：亲子公开课、校园体验日、主题挑战。
  • 产品理念：玩学理念、课堂方式、POKI 陪伴感。
  • 风采展馆：小队作品、课堂高光、纪念卡、闪卡。

文案限制

  • 孩子能看到的文案：尽量 2-8 个字。
  • 老师需要理解的说明：最多一行。
  • 抽屉要点：最多 3 条。
  • 禁止出现：AI 思考过程、产品内部推理、过长品牌介绍。

交互动效

  1. 活动小球 hover：轻微上浮，表示可点击。
  2. 活动小球 active：增加亮边或发光，表示当前选中。
  3. 活动抽屉出现：从右侧滑入，时长 240-320ms。
  4. 活动抽屉关闭：淡出或滑回右侧，时长 180-240ms。
  5. 主题书签切换：选中书签向右突出，课程地图内容平滑替换。
  6. 课程节点引导：POKI 图标轻微上下浮动，吸引孩子点击当前节点。

验收标准

  1. UI 设计师能根据本文档画出首页线框图，不需要再追问页面分区。
  2. 首页第一视觉焦点是课程节点地图，不是活动、商城或导航。
  3. 右侧小球只放课程外内容：线下活动、产品理念、风采展馆。
  4. 点击小球弹出的是活动内容面板，不是跳转到底部导航页。
  5. 活动抽屉有明确内容结构：图标、标签、标题、说明、三条要点。
  6. 主题书签保持左侧竖向结构，不改成横向排列。
  7. 页面整体风格能复用到课程外页面，形成统一的 POKI 玩具盒式课堂 UI。
