V1 / 开发对接

POOK AI 课堂端 V1 开发文档

这里只放开发需要直接阅读的文档。原型入口仍然是站点根路径，本文档入口建议使用 /docs/ 或 /docs/index.html。

阅读顺序 先看主文档，再按模块补充。

后端先看数据链路，前端先看全流程 UI 总纲。所有人都需要先理解 V1 范围和设计适配规范。

  • 后端重点：账号、小队、课程解锁、奖励、成长卡、商城兑换。
  • 前端重点：页面顺序、组件状态、动效、适配、课程环节交互。
  • 共同重点：V1做什么、不做什么、哪些数据按小队归属。

按开发角色阅读，不再展示完整作品集。
