课前目标建立与使命感设计PRD

我希望这个环节不只是让孩子看到接下来要做什么，而是让孩子知道：今天为什么要做、做完我会变强什么、接下来怎么完成。

阅读说明 先看结论，再看细节。

这份文档围绕《课前目标建立与使命感设计PRD》展开，重点不是堆功能，而是把模糊讨论收口成可判断、可协作、可开发或可验收的产品依据。

  • 简单摘要：先确认本文解决的问题、核心结论和适用版本。
  • PM价值：把真实场景、用户问题、业务规则和执行边界讲清楚，减少团队理解偏差。
  • 使用方式：老板看结论和风险，设计看页面目标，开发看规则和验收口径。

价值摘要

01

把“目标页”从课程内容预览，升级为课前意义建立。

02

让孩子先理解使命，再理解能力，最后才看任务路径。

03

让教育价值不只藏在老师教案里，而是在产品界面中被孩子感知。

1. 背景

当前目标页已经能展示问题、模型和合作任务，但它更像“课程内容预览”。

这个方向虽然比文字列表更低龄友好，但还没有真正突出“目标”的意义。

2. 问题定义

  1. 孩子知道等一下会做什么，但不一定知道为什么要做。
  2. 模型预览太强，会让目标页变成具体课程内容展示。
  3. 能力点存在，但不够儿童化，孩子感知不到“我会变强”。
  4. 合作任务被展示了，但还没有和“完成使命”建立关系。

3. 页面定位

目标页应该定义为：

课前目标建立页：先建立今天的小使命，再点亮孩子能理解的能力，最后用很短的方式预告任务路径。

它不是：

  • 课程内容预览页
  • 学习目标文字页
  • 模型展示页

4. 方案设计

4.1 第一阶段：今天的小使命

先告诉孩子今天为什么要做。

  • 例：犀牛身上脏了，它需要一个可以洗澡的地方。
  • POKI 话术：今天我们要帮它解决一个小问题。
  • 画面重点：角色、问题、需要帮助。

4.2 第二阶段：我会变强什么

把能力点翻译成孩子能理解的话。

  • 观察力：我会看一看
  • 搭建力：我会搭出来
  • 合作力：我会一起做
  • 表达力：我会说出来

4.3 第三阶段：怎么完成

最后才简短预告任务路径。

  • 先观察问题
  • 再找积木
  • 一起搭出来
  • 最后讲作品

5. 交互规则

  1. 进入目标页后，默认展示“小使命”。
  2. 每段展示 10 秒，自动进入下一段。
  3. 第三段停留，不自动进入课堂。
  4. 教师可随时点击“进入课堂”。
  5. 问题卡片和模型预览降级为辅助信息，不再作为目标页主视觉。
  6. 画面文字尽量短，解释性信息交给 POKI 说，话术要接近幼教老师的口吻。

6. 验收标准

  1. 孩子能看懂今天为什么要做。
  2. 页面能表达“我会变强什么”。
  3. 页面能保留简短任务路径，但不变成具体内容预览。
  4. 右侧 POKI 讲解与左侧主内容一致。
  5. 页面仍保持低文字密度和自动化节奏。
