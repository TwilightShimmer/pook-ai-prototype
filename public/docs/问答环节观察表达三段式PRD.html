问答环节观察表达三段式PRD

把问答环节从“读题答题”，改成低龄孩子更容易进入的“观察表达”。

  • 核心用户：4-6岁儿童
  • 设计原则：短链路、少文字、先说后选
  • 目标：看懂问题，并说出一个观察
PRD / 课程环节

问答环节观察表达三段式PRD

现在问答环节的问题不是提示不够，而是问题太复杂、等待回答时没有支架。这个环节应该更像幼教课堂里的“看一看，说一说”，而不是传统选择题。

阅读说明 先看结论，再看细节。

这份文档围绕《问答环节观察表达三段式PRD》展开，重点不是堆功能，而是把模糊讨论收口成可判断、可协作、可开发或可验收的产品依据。

  • 简单摘要：先确认本文解决的问题、核心结论和适用版本。
  • PM价值：把真实场景、用户问题、业务规则和执行边界讲清楚，减少团队理解偏差。
  • 使用方式：老板看结论和风险，设计看页面目标，开发看规则和验收口径。

价值摘要

01

降低理解门槛：问题由 POKI 说，屏幕只放短词和图。

02

保留学习动作：孩子仍然要观察、表达、确认。

03

增加等待支架：孩子不会说时，POKI 给短提示。

1. 问题定义

  1. 原问题过长，孩子不一定听懂，也不一定能读懂。
  2. 等待孩子回答时，页面缺少持续引导。
  3. 直接展示文字选项，会让低龄孩子变成猜题。
  4. 问答环节需要保留“学到东西”，不能只变成点击按钮。

2. 页面定位

问答环节改名为“看一看”。

它不是考试题，而是让孩子先观察，再说一个发现，最后用图片选择确认理解。

3. 三段式流程

3.1 第一段：看一看

POKI 用幼教口吻介绍问题，主画面展示图片。

  • 屏幕短词：看一看
  • POKI 话术：宝贝们，看一看，小犀牛怎么啦？
  • 目标：让孩子先知道观察对象。

3.2 第二段：说一说

先让孩子口头发言，不急着展示选项。

  • 屏幕短词：说一说
  • 等待提示轮播：颜色 / 身体 / 角 / 脏脏的
  • 老师可以点击“听到了”进入下一段。

3.3 第三段：选一选

语音互动后，再展示图片化选项，作为理解确认。

  • 屏幕短词：选一选
  • 选项以图标和短词呈现，不使用长文字按钮。
  • 选中后给鼓励反馈，再进入下一环节。

4. 交互规则

  1. 默认进入“看一看”。
  2. 点击“我看到了”进入“说一说”。
  3. 说一说阶段持续展示短提示轮播。
  4. 点击“听到了”进入“选一选”。
  5. 选一选阶段展示图片/图标选项。
  6. 正确选择后，问答环节完成。
  7. 错误选择不强惩罚，只提示再看一眼。

5. 验收标准

  1. 页面不再展示大段问题说明。
  2. 等待回答时必须有引导提示。
  3. 孩子先发言，再看到选择项。
  4. 选择项为图标/图片化卡片，不是长文字按钮。
  5. POKI 话术符合幼教风格。
