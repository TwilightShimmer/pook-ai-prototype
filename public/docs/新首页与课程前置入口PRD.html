新首页与课程前置入口PRD

阅读说明 先看结论，再看细节。

这份文档围绕《新首页与课程前置入口PRD》展开，重点不是堆功能，而是把模糊讨论收口成可判断、可协作、可开发或可验收的产品依据。

  • 简单摘要：先确认本文解决的问题、核心结论和适用版本。
  • PM价值：把真实场景、用户问题、业务规则和执行边界讲清楚，减少团队理解偏差。
  • 使用方式：老板看结论和风险，设计看页面目标，开发看规则和验收口径。

价值摘要

01

这份需求在解决：首页主次关系错误，关键上课流程没有占据主舞台的问题。

02

这份需求值得做：它会直接影响用户进入产品后第一眼看到什么、先做什么。

03

这份需求体现的产品判断：首页中心应该服务选课，活动、展览和商业化信息都应该被收纳和弱化。

1. 背景

我不是只想换首页样式。 我是在重做首页的信息优先级。

旧首页主要展示的是：

  1. 线下活动信息
  2. 其它小队的学习记录 / 高光记录
  3. 商业化信息
  4. 其它外围内容

这些都不属于关键上课流程。

所以我的判断是：

新首页应该直接服务于选课和上课。

2. 问题定义

当前首页的问题不是信息少。 而是主次关系不对。

具体表现：

  1. 关键上课流程没有被放在首页主舞台
  2. 次要内容占据了中心注意力
  3. 功能卡片过重，不像低龄产品入口
  4. 容易让用户先看外围信息，而不是直接开始课程

3. 目标

我希望新首页做到两件事：

  1. 首页中心直接服务选课
  2. 次要信息被收纳、被弱化，但不丢失

4. 版本范围

本需求覆盖：

  1. 新首页主舞台
  2. 首页课程前置入口
  3. 次要信息的活动球收纳形式
  4. 页面文案与视觉表达原则

5. 方案设计

5.1 中间主舞台

首页中间只做一件事：

课程选择

结构建议：

  • 左侧书签式主题
  • 中间课程节点 / 课程卡
  • 明确一个“开始这节课”的主 CTA

5.2 右侧活动悬浮球

原本首页那些非关键流程信息，不删。 但要弱化成：

活动悬浮小球

这些球承载的是：

  • 线下活动
  • 高光记录展览馆
  • 商业化信息
  • 其它外围入口

6. 关键规则

6.1 首页主任务规则

首页主任务必须是：

  • 先选主题
  • 再开始今天的课程

6.2 次要信息规则

活动、展馆、商业化信息都属于次要信息。 它们不能继续占据首页主舞台。

6.3 活动球规则

  1. 小球集中在页面右侧
  2. 每个小球之间保持一定距离
  3. 不均匀铺满页面
  4. 最右侧增加 》 收起按钮

6.4 文案规则

页面上不应该出现 AI 思考过程感的语言。 也不应该把设计 reasoning 写给用户看。

文案要求：

  • 面向孩子
  • 面向上课动作
  • 面向当前任务

6.5 主题切换规则

课程主题继续保留书签式结构。 不要改成一排横向标签。

7. 数据与内容要求

首页至少需要支持两类内容：

  1. 主流程内容
  • 课程主题
  • 推荐课程
  • 开始课程入口
  1. 次要内容
  • 活动信息
  • 高光记录 / 展馆入口
  • 商业化信息
  • 其它外围内容

8. 验收标准

  1. 首页主视觉聚焦选课
  2. 次要信息被收纳到右侧活动球
  3. 小球集中在右侧，不均匀平铺
  4. 有 》 收起入口
  5. 页面文案没有 AI 思考过程感
  6. 主题切换仍然是书签式

9. 暂不纳入

这轮先不做：

  1. 复杂首页社交关系
  2. 多层活动球聚合逻辑
  3. 首页上的成长与展馆深度联动

先把首页主次关系调对。
