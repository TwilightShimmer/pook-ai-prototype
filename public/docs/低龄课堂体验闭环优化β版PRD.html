低龄课堂体验闭环优化β版PRD

阅读说明 先看结论，再看细节。

这份文档围绕《低龄课堂体验闭环优化β版PRD》展开，重点不是堆功能，而是把模糊讨论收口成可判断、可协作、可开发或可验收的产品依据。

  • 简单摘要：先确认本文解决的问题、核心结论和适用版本。
  • PM价值：把真实场景、用户问题、业务规则和执行边界讲清楚，减少团队理解偏差。
  • 使用方式：老板看结论和风险，设计看页面目标，开发看规则和验收口径。

价值摘要

01

这份需求在解决：低龄课堂从进入课程到结束课程之间，体验不成闭环的问题。

02

这份需求值得做：它决定孩子能不能顺利进入、参与并记住一节课。

03

这份需求体现的产品判断：低龄产品要先补齐“课前承接 - 课中引导 - 课后沉淀”，再谈功能扩展。

1. 背景

这版我不想继续做大而全扩展。 我想先把低龄课堂最基础、最核心的体验闭环补齐。

现在的问题很明确：

  1. 课前缺少承接
  2. 课中缺少引导
  3. 课后缺少沉淀

一句话说：

课前要知道今天做什么，课中要知道现在做到哪，课后要看到我完成了什么。

2. 问题定义

2.1 课前问题

孩子进入课程后，不知道：

  • 上次做了什么
  • 今天为什么回来
  • 今天这一节要完成什么

2.2 课中问题

课堂过程中容易出现：

  • 不知道当前到哪一步
  • 不知道下一步做什么
  • 需要频繁依赖老师额外解释

2.3 课后问题

课程结束后：

  • 孩子不容易记住自己完成了什么
  • 家长看不到明确结果
  • 机构也看不到可复用的课堂成果沉淀

3. 目标

这版目标不是堆功能。 是把“一节课”做成完整体验。

我希望孩子进入课程后，至少能明确三件事：

  1. 我回来了
  2. 我今天要做什么
  3. 我刚刚完成了什么

4. 版本范围

本版本只做 6 个 P0 需求：

  1. 课前欢迎页
  2. 上节课回顾 + 本节课目标页
  3. 课堂流程进度提示
  4. 问答环节首次强引导
  5. 课后成长卡
  6. 能力标签基础框架

5. 方案设计

5.1 课前欢迎页

作用：

  • 降低进入课堂的启动摩擦
  • 建立回归感和陪伴感

页面要素：

  • POKI / Pooki 形象
  • 欢迎文案
  • 今日课程主题氛围图
  • 开始今天的任务按钮
  • 非首次上课时的上节课回顾入口

5.2 目标提示页

作用：

  • 让孩子知道上次做了什么
  • 让孩子知道今天要做什么
  • 让孩子知道完成后会获得什么

页面要素：

  • 上节课完成内容
  • 本节课主题
  • 本节课任务列表
  • 完成后可点亮的能力标签
  • 进入课堂按钮

5.3 课堂流程进度组件

作用：

  • 持续告诉孩子和老师当前处于哪一步

默认节点建议：

  • 课程介绍
  • 视频引入
  • 问答互动
  • 找积木
  • 固定拼搭
  • 自由拼搭
  • 作品分享
  • 课堂评价

5.4 问答首次强引导

首次进入问答时，不直接提问。 先走四步：

  1. 说明任务
  2. 示例回答
  3. 提示卡片
  4. 等待回答

5.5 课后成长卡

作用：

  • 把一次课堂结果沉淀下来

页面要素：

  • 课程主题
  • 作品照片
  • 本节课完成任务
  • 点亮的能力标签
  • Pooki 鼓励语
  • 获得的勋章
  • 保存 / 分享 / 返回首页

5.6 能力标签基础框架

作用：

  • 替代成人化分数评价
  • 让家长和机构更容易理解素质教育价值

6. 关键规则

  1. 欢迎页必须先于正式课堂出现
  2. 目标页必须明确“过去 / 现在 / 收获”
  3. 流程组件不能只是装饰，要随课堂步骤变化
  4. 问答首次引导必须保留思考时间
  5. 课后成长卡必须能直接承接课堂结果
  6. 能力标签先按课程目标配置，β 版不做复杂算法

7. 数据要求

这版必须配置化，不能写死在页面里。

至少需要抽离：

  1. 欢迎文案
  2. 上节课回顾
  3. 本节课目标
  4. 流程节点
  5. 问答引导话术
  6. 成长卡内容
  7. 能力标签配置

8. 验收标准

产品验收

  1. 用户进入课程后先看到欢迎页
  2. 欢迎后能进入目标页
  3. 课堂中始终有进度提示
  4. 问答首次引导可完整走通
  5. 课程结束能生成成长卡

体验验收

  1. 文案短句化
  2. 每屏只有一个主目标
  3. 不依赖孩子大量阅读
  4. 关键步骤有明确反馈

9. 暂不纳入

这版先不做：

  1. 复杂算法判断
  2. 多套评分系统
  3. 大而全成长体系
  4. 复杂社交功能

我希望 β 版先把课堂体验闭环补齐，再往外扩。
