PRD / 首页 UI 开发

首页课程地图居中与活动入口精简 UI 开发 PRD

本轮目标：让首页更像低龄孩子能理解的闯关地图，减少成人网页式标题、二次确认和重复 CTA。

阅读说明 先看结论，再看细节。

这份文档围绕《首页课程地图居中与活动入口精简 UI 开发 PRD》展开，重点不是堆功能，而是把模糊讨论收口成可判断、可协作、可开发或可验收的产品依据。

  • 简单摘要：先确认本文解决的问题、核心结论和适用版本。
  • PM价值：把真实场景、用户问题、业务规则和执行边界讲清楚，减少团队理解偏差。
  • 使用方式：老板看结论和风险，设计看页面目标，开发看规则和验收口径。

文档信息

页面首页
优先级P0
使用者老师 / 4-6岁儿童
开发目录VUE3-β原型
核心组件课程地图 / 主题书签 / 活动小球
更新时间2026-05-18

本轮决策

01

删除顶部“点亮第一关，跟 POKI 开始”。它和课程节点引导重复，会让首页像网页 hero，而不是课程地图。

02

删除选择主题后的左上角二次提示。主题状态由左侧书签高亮、课程地图切换和背景视觉变化表达。

03

删除紫色“开始”按钮。首页主操作只保留“点击当前亮起课程节点开始”。

04

活动小球删除“合作机构”。能进入 App 的人默认已经是合作机构老师，不需要在首页再次解释合作。

页面布局

整体容器

  • 首页主容器高度占满当前 screen 内容区。
  • 主容器内只保留课程选择区，不再保留顶部标题区。
  • 主容器右侧预留活动小球区域，避免课程地图被小球遮挡。
  • 课程选择区垂直居中，视觉中心略高于屏幕正中，避免底部导航造成压迫。

建议布局参数

主容器 padding

上/下 28px，左 30px，右侧至少 220px 预留给活动小球。

课程区高度

建议高度 min(620px, 100%)，并在主容器内垂直居中。

主题栏宽度

左侧主题书签区固定约 188px，书签按钮宽 122px。

课程地图高度

地图容器建议 min-height: min(500px, 100%)，内部上下 padding 约 48px。

组件规格

1. 主题书签 ThemeRail

  • 位置：页面左侧，垂直排列。
  • 按钮尺寸：宽 122px，最小高度 138px。
  • 图标区域：84px × 84px，圆角 26px。
  • 选中态：向右拔出约 12px，整体缩放 1.03，边框高亮。
  • 文字：只保留短标签，例如“生命”“自然”“工程”“人文”。
  • 不要额外在页面左上角重复显示“当前主题”。

2. 课程地图 CourseMap

  • 位置：页面中心主体。
  • 形态：五个圆形课程节点，虚线连接，呈轻微蜿蜒路径。
  • 容器圆角：32px。
  • 节点尺寸：120px × 120px。
  • 节点图形区域：76px × 76px，圆角 24px。
  • 当前可上节点：第一个节点高亮，显示 POKI 引导。
  • 未解锁节点：降低饱和度，显示“待解锁 / 锁定”。
  • 点击当前节点：进入课程。
  • 点击未解锁节点：toast 提示“先从亮起来的小圆点开始吧”。

3. POKI 节点引导

  • 位置：当前可上节点上方。
  • 图形：暂用机器人 icon/emoji，占位 POKI IP。
  • 文案：最多 6 个汉字，例如“跟 POKI 来”。
  • 动效：上下轻微 bounce，引导孩子看向当前节点。
  • 不要再在页面顶部放独立欢迎语。

4. 活动小球 ActivityBubble

  • 位置：页面右侧中部，垂直排列。
  • 保留入口：线下活动、产品理念、风采展馆。
  • 删除入口：合作机构。
  • 小球尺寸：118px × 118px，圆形。
  • 间距：16px。
  • 内容：emoji/icon + 2-4字标题。
  • 收起按钮：58px × 58px，圆形，位于小球右侧。

5. 活动信息抽屉 ActivityDrawer

  • 点击活动小球后在首页内弹出，不进入新页面。
  • 抽屉宽度建议不超过 370px。
  • 抽屉最小高度约 360-440px。
  • 结构：关闭按钮、图标、短标签、标题、摘要、三条要点。
  • 关闭按钮：42px × 42px，圆形，右上角。
  • 抽屉不应覆盖课程地图的关键节点。

交互规则

  1. 用户进入首页后，第一视觉应落在课程地图，而不是标题或按钮。
  2. 主题切换只通过左侧书签完成，不新增顶部主题确认区域。
  3. 开始课程只通过当前亮起节点完成，不提供第二个“开始”按钮。
  4. 未解锁课程节点可以点击，但只提示，不进入课程。
  5. 活动小球是次级入口，点击后展开抽屉；收起后关闭已打开抽屉。
  6. 右侧活动入口不包含“合作机构”。

动效要求

  • 主题书签选中：180ms 内完成右移和缩放。
  • 当前课程节点：保持轻微高亮，不做强烈闪烁。
  • POKI 引导：1.2s 左右上下浮动循环。
  • 活动小球收起：依次向右缩小并淡出，间隔约 80ms。
  • 活动抽屉：从右向左滑入，约 260ms。
  • 所有动效都服务“引导点击当前节点”，不能抢课程地图注意力。

文案规则

  • 首页不写产品解释，不写 AI 思考过程语。
  • 不再出现“点亮第一关，跟 POKI 开始”。
  • 不再出现“主题 / 生命科学”这种二次确认文案。
  • 节点引导文案必须靠近节点，例如“跟 POKI 来”。
  • 活动小球标题控制在 2-4 字：线下活动、产品理念、风采展馆。

验收标准

  1. 首页顶部没有“点亮第一关，跟 POKI 开始”。
  2. 课程地图上方没有主题二次提示和紫色开始按钮。
  3. 课程地图在页面视觉中心区域，不下沉。
  4. 点击当前亮起课程节点可以进入课程。
  5. 点击未解锁课程节点只出现 toast。
  6. 右侧活动小球只剩三个：线下活动、产品理念、风采展馆。
  7. 活动小球中不再出现合作机构。
  8. 页面仍然保持低龄友好：图像优先、文字少、操作入口单一。
