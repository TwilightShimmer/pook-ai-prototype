UI 原型 PRD / 我的

“我的”页面小队管理台 UI 原型 PRD

这个页面给老师用，不给孩子做个人中心。核心任务是：确认当前小队，看小队账户，快速进入上课。

阅读说明 先看结论，再看细节。

这份文档围绕《“我的”页面小队管理台 UI 原型 PRD》展开，重点不是堆功能，而是把模糊讨论收口成可判断、可协作、可开发或可验收的产品依据。

  • 简单摘要：先确认本文解决的问题、核心结论和适用版本。
  • PM价值：把真实场景、用户问题、业务规则和执行边界讲清楚，减少团队理解偏差。
  • 使用方式：老板看结论和风险，设计看页面目标，开发看规则和验收口径。

页面定位

“我的”不是儿童个人中心，也不是品牌介绍页。

它应该是老师的课堂操作台：老师进来后，第一眼确认现在是哪支小队，第二步选择是否切换小队，第三步进入上课或查看成长。

01

核心动作：选中当前上课小队。

02

核心信息：当前小队的奖励账户和成长资产。

03

核心边界：不要把产品解释、设计意图、页面定位写进页面里。

UI 风格

沿用“POKI 玩具盒式课堂 UI”，但老师页面需要比孩子页面更收敛。

  • 保留大圆角、大按钮、彩色反馈，让课堂环境里看得清。
  • 减少装饰，优先让老师一眼扫到小队编号和账户数据。
  • 卡片可以有颜色，但不要过度儿童化，避免像孩子游戏页。
  • 页面文字短，不解释产品逻辑，只服务操作。

页面结构

整体布局

页面采用左右两栏。

  • 左侧大栏：当前小队 + 小队切换 + 主要操作按钮。
  • 右侧小栏：当前小队账户数据 + 状态摘要。

信息优先级

  1. 当前小队编号和名称。
  2. 1-4 号小队切换卡片。
  3. 星星、经验、宝石、纪念卡。
  4. 开始上课、查看成长、课堂辅助设置。
  5. 机构与数据归属说明。

模块说明

当前小队头部

展示当前小队编号、名称、成员数和简短备注。编号要最大，方便老师远距离确认。

小队切换卡片

展示 1-4 号小队。当前小队高亮。卡片内展示人数和最近一次课堂状态。

小队账户

展示累计星星、累计经验、宝石积分、纪念卡数量。数据必须随小队切换立即变化。

操作入口

保留三个主入口：用当前小队开始上课、查看当前小队成长记录、课堂辅助设置。

顶部小队胶囊

其它页面点击顶部当前小队时，先弹算术验证码，再出现小队切换弹窗。

老师验证码

进入“我的”前验证一次。进入后，页内切换小队不再重复验证。

交互规则

  1. 从底部导航进入“我的”：先出现算术验证码。
  2. 验证码通过：进入“我的”页面。
  3. 在“我的”页面点击小队卡片：直接切换当前小队，不重复验证。
  4. 切换小队后：左侧当前小队、右侧账户数据、顶部小队胶囊同步更新。
  5. 点击“用当前小队开始上课”：回到首页，后续课程数据归属当前小队。
  6. 点击“查看当前小队成长记录”：进入成长中心，默认展示当前小队。
  7. 点击“课堂辅助设置”：仍按老师设置规则弹算术验证码。

文案规则

  • 页面内只写老师需要看到的操作信息。
  • 不要出现“本页定位”“这个页面给老师用”等产品解释型文案。
  • 小队状态文案要短，比如：等待开始、刚完成课程、需要更多引导。
  • 按钮文案必须指向动作，比如：开始上课、查看成长、课堂设置。
  • PRD 可以解释设计意图，页面原型不解释设计意图。

验收标准

  1. 老师进入页面后，能立刻看到当前小队。
  2. 1-4 号小队卡片清楚可点，当前小队高亮。
  3. “我的”页内切换小队不出现二次验证码。
  4. 右侧账户数据随小队切换变化。
  5. 页面不出现产品定位、设计说明、AI 过程语。
  6. 按钮入口不超过三个主动作，避免老师课堂中误触。
  7. 整体风格和首页、成长中心保持同一套 POKI 玩具盒式课堂 UI。
