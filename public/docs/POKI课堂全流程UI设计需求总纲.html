按页面顺序整理全流程 UI、组件和动效要求。用于后续高保真视觉和组件化开发。

  • 目标用户：4-6岁儿童、机构老师/助教
  • 核心场景：合作机构课堂
  • 核心风格：POKI 玩具盒式课堂 UI

POKI 课堂全流程 UI 设计需求总纲

这份文档把已经定下来的页面逻辑翻译成 UI 设计要求：每个页面要出现什么组件、主体视觉放什么、动效怎么服务课堂，而不是做装饰。

阅读说明 先看结论，再看细节。

这份文档围绕《POKI 课堂全流程 UI 设计需求总纲》展开，重点不是堆功能，而是把模糊讨论收口成可判断、可协作、可开发或可验收的产品依据。

  • 简单摘要：先确认本文解决的问题、核心结论和适用版本。
  • PM价值：把真实场景、用户问题、业务规则和执行边界讲清楚，减少团队理解偏差。
  • 使用方式：老板看结论和风险，设计看页面目标，开发看规则和验收口径。

总原则

儿童看图

4-6 岁孩子不依赖阅读完成操作。页面先给图像、颜色、角色和动作，文字只做极短辅助。

老师控场

老师需要快速确认当前小队、当前环节、上一步/下一步、退出和设置入口。所有老师入口要有验证码保护。

系统推进

POKI 主导语音和阶段提醒。能自动推进的地方不要求孩子或助教频繁点击。

全局组件拆解

1. 顶部状态栏 AppChrome

  • 左侧：返回按钮。课程中点击退出要二级确认；非课程页返回上一页。
  • 中间：当前页面标题，短词，不写说明句。
  • 右侧：当前小队胶囊 + 宝石余额 + 我的入口。
  • 点击当前小队胶囊：先算术验证码，再弹小队切换面板。

2. 底部主导航 AppDock

  • 样式：圆角胶囊容器，按钮用 emoji/icon + 2字标签。
  • 功能：首页、探索、见面、商城、成长、我的。
  • 激活态：高亮背景，不依赖大段文字解释。
  • 课程流程内也显示，但不能遮挡主内容和课程进度栏。

3. 课程底部进度栏 LessonNav

  • 包含：阶段描述、流程线、经验值、星星罐子。
  • 上下步按钮是独立容器，放在进度栏左右两端，不塞进进度栏。
  • 进度栏与上方主容器必须有明显间距，不能重叠。
  • 流程线要足够长，避免节点挤在一起。

4. 右侧信息栏 / 活动抽屉

  • 作为主容器的补充信息层，不覆盖主容器边框。
  • 弹出时只显示自身大小，不再套一个更大的外容器。
  • 用于：活动侧栏、课程欢迎补充信息、见面分工、目标/问答阶段提示。
  • 动效：从右侧滑入，220-360ms，丝滑但不抢戏。

5. POKI 角色组件

  • 当前先用机器人 emoji/icon 占位，后续替换 1:2 身材 IP。
  • 说话时有轻微上下浮动或呼吸动效。
  • 信息逐条出现：POKI 说到第几条，就展示第几条卡片。
  • 不要让 POKI 遮挡课程主视觉。

6. 验证码弹窗

  • 用于老师入口：我的、教师设置、顶部小队切换、成长页小队切换。
  • 题型：乘法/除法，避免孩子误入。
  • 进入“我的”验证一次后，页内切换小队不重复验证。
  • 弹窗出现时页面其它按钮不可点击。

全局线框示意

顶部状态栏：返回 / 页面标题 / 当前小队 / 宝石 / 我的
主内容容器：页面核心视觉，不被底部导航遮挡
右侧信息栏：必要时滑入，非必要隐藏
首页探索商城成长我的

页面顺序与 UI 需求

01 首页：课程入口 + 活动侧栏

课程外默认首页孩子和老师都能看
POKI 提示：点亮第一关
左侧主题书签：图片/图标优先
12345
活动理念机构展馆

必要组件

  • 课程主题书签：生命科学、自然科学、工程科学、社会人文。
  • 课程节点地图：蜿蜒小路，不是直线导航。
  • 当前可上课程节点：高亮、POKI 引导。
  • 右侧活动小球：线下活动、产品理念、风采展馆。
  • 活动抽屉：点击小球后弹出，不跳转到底部导航页。

节点轻微浮动活动抽屉右滑POKI 提示呼吸

主体视觉：课程选择必须是首页第一视觉。活动和商业信息只能收纳在侧边，不抢主舞台。

02 探索页：更多课程地图

课程外选课扩展可滑动
左侧主题 Tag：图片化标签，选中像书签拔出
12345

必要组件

  • 左侧主题页签：低文字，图片/颜色标识主题。
  • 每个主题 5 个小球节点。
  • 未解锁节点点击 toast：先选择当前已解锁课程。
  • 页面可上下滑动；滑到底继续下滑切换下一主题，向上回切上一个主题。

主题切换滑动节点解锁发光未解锁轻震

主题标签不要横向排满文字，应像儿童绘本里的彩色书签。

03 商城页：套件商城 + 积分商城

课程外商业化成人主导
左侧页签：推荐 / 乐高教育 / POOK 3D / 耗材 / 积分商城
商品卡片区：套件或积分奖励

必要组件

  • 左侧垂直页签，作为其它成人页的参考样式。
  • 套件卡：产品图占位、价格、适合年龄、课程价值。
  • 积分商城：贴纸、勋章、卡片等实物小奖励。
  • 兑换二级确认：复杂乘除法，防止孩子误购买。
  • 积分余额读取当前小队宝石。

页签切换淡入兑换弹窗聚焦

这是成人决策页面，颜色可以丰富，但信息密度要比儿童上课页更高。

04 我的页：老师的小队管理台

课程外老师使用进入前验证码
当前小队 + 1-4号小队切换卡片 + 主操作按钮
小队账户：星星 / 经验 / 宝石 / 纪念卡

必要组件

  • 当前小队头部：编号最大，名称、成员数、最近表现。
  • 小队切换卡：1-4号，当前队高亮。
  • 小队账户卡：累计星星、累计经验、宝石、纪念卡。
  • 操作按钮：用当前小队开始上课、查看成长、课堂辅助设置。
  • 页面内不要写“本页定位”等产品解释。

进入前验证码页内切换无二次验证数据同步跳变

这是老师效率页，不是孩子个人中心。视觉要清楚、稳定、可扫读。

05 见面环节：拍照识别 + 自动分工

课程内自动推进视频流主视觉
大圆角容器：视频流占据主体
识别完成后视频流等比例缩到左侧；下方显示 1-4 编号
右侧分工栏：POKI + 角色卡逐条出现

必要组件

  • 主视频画框：进入时占据课程内容容器，不被底部进度栏遮挡。
  • 扫描动效：轻量，不像复杂安防系统。
  • 儿童识别编号：1-4号，显示在缩小画框下方。
  • 右侧 POKI 分工栏：建造家、指挥者、观察员、分享员等。
  • POKI 说到第几个角色，下方第几个卡片出现。

视频框缩放右栏滑入角色卡依次出现5s 节奏

主容器、右侧栏、底部进度栏必须相互独立，任何区域不能重叠。

06 欢迎页：POKI 先说，再播放视频

课程内语音优先视频辅助
视频画框：进入时暂停首帧，POKI 讲完后自动播放
POKI 右侧信息栏：欢迎语、主题介绍、简短提示

必要组件

  • 视频画框：首帧静止，避免和 POKI 语音抢注意力。
  • POKI 说话栏：先欢迎，再介绍今天主题。
  • 补充卡片：文字小、短、图形化。
  • 播放状态：POKI 说完后视频开始，播放中不叠过多文字。

右栏滑入文本逐条出现视频延迟播放

不要一边说话一边放视频。低龄孩子注意力要被系统分阶段引导。

07 目标页：任务主线建立

课程内10s 节奏使命感
主视觉：先问题卡片，再积木建模任务
POKI：幼教风格讲解，少字，多图

必要组件

  • 今日任务视觉：要帮谁、解决什么问题、最后搭什么。
  • 问答预告卡：展示接下来会观察/回答的问题。
  • 积木模型预告：用图像告诉孩子最终拼搭方向。
  • 社会属性任务：合作找积木、合作拼搭、分享作品成果。
  • POKI 台词：幼教口吻，简短、有鼓励。

10s 自动节奏卡片依次出现POKI 引导

目标页不是课程内容预览，而是让孩子知道“我们今天要一起完成一件事”。

08 问答页：观察表达三段式

课程内少文字先说后选
阶段 1：POKI 简单介绍问题 + 大图片
阶段 2：等待孩子发言，给语音/图像提示
阶段 3：展示图片选项，让孩子选择作答

必要组件

  • 问题标题必须极短，避免复杂句。
  • 大图片作为理解入口，而不是装饰。
  • 发言等待态：POKI 给提示，不能空等。
  • 图片选项：孩子听不懂或说不出时，用选择完成表达。
  • 答对/完成反馈：POKI 鼓励 + 进入下一环节。

三段自动推进等待态呼吸选项点亮

问答不是考孩子识字，而是帮助孩子观察、表达和确认理解。

09 找积木页：颜色数量确认

课程内现实场景强色块识别
左侧：当前要找的积木大图、颜色、数量、阶段流程
右侧：视频流，孩子举起积木给 POKI 看

必要组件

  • POKI 先说明：现在要找什么，找完举起来。
  • 当前积木卡：形状、颜色、数量都要大且清楚。
  • 阶段进度：一块一块找，不一次展示过多。
  • 视频确认区：技术上先识别色块数量，不强行识别具体形状。
  • 确认反馈：找对、再看看、还差几块。

当前积木切换颜色识别反馈POKI 提醒

这个页面要减少孩子反复问老师“是不是这个”的次数。

10 固定拼搭页：步骤跟随

课程内结构任务防止一人独占
主模型步骤：当前步骤大图 / 完成效果
角色协作提示：谁找、谁拼、谁检查

必要组件

  • 当前步骤图：只展示当前要做的拼搭动作。
  • 完成对照图：孩子知道拼到什么样。
  • 角色轮换提示：避免一个孩子一直拼，其他孩子插不上手。
  • 完成按钮/自动确认：老师可控制进入下一步。

步骤卡滑动完成态打勾角色提示闪烁

固定拼搭的 UI 不只是教拼搭，还要帮助老师分配参与机会。

11 自由拼搭页：显性引导 + 时间边界

课程内创造环节倒计时花朵
主容器：作品扩展区、灵感提示、POKI 鼓励
动画倒计时：花朵逐渐点亮/收束

必要组件

  • POKI 先说明：可以加什么，不是完全空白自由发挥。
  • 灵感卡：3个图像化方向，例如加水、加路、加朋友。
  • 倒计时花朵：防止长时间停留，帮助老师控时。
  • 鼓励机制：提前完成可给小队更多宝石/星星。

花朵倒计时灵感卡浮入POKI 鼓励

自由拼搭不是不给引导，而是给孩子看得懂、可选择的创作方向。

12 分享页：作品表达

课程内表达能力POKI 辅助
作品画框/拍摄画面
表达提示：我的作品叫… 它可以… 我最喜欢…

必要组件

  • 作品展示主画框：让孩子看到自己搭的东西。
  • POKI 提问：一句一句问，不同时给三四个问题。
  • 表达模板：给不会说的孩子补句式。
  • 小队轮流提示：让每个孩子都有发言机会。

发言卡逐条出现录音波形轮流提示

分享页不是“展示成果”而已，还要降低孩子开口表达的难度。

13 结课成长卡：小队奖励入账

课程内结果反馈归属小队
标题：当前小队 · 课后成长卡
作品照片 / 完成任务 / POKI 评价
奖励：宝石 + 纪念卡 + 星星/XP 总结

必要组件

  • 小队归属标题：明确奖励进入哪个小队。
  • 完成任务列表：只显示孩子做过的关键动作。
  • 能力标签：观察、动手、合作、表达。
  • 奖励卡：宝石、纪念卡，新卡/已收藏状态。
  • 返回首页按钮。

奖励卡弹出新卡闪光返回过渡

结课页的重点是“本次课程有结果”，且结果属于当前小队。

14 成长中心：小队数字展馆

课程外记录沉淀按小队切换
顶部：当前小队 + 快速切换
统计：卡片 / 星星 / XP / 宝石 / 完成课程
数字展馆：纪念卡、闪卡、作品记录

必要组件

  • 当前小队标识。
  • 小队切换入口：成长页切换前需要验证码。
  • 小队数据统计：不展示全局账号数据。
  • 纪念卡展馆：完成一次课程发一张，不重复发。
  • 主题闪卡：每个主题表现最好课程的卡片可升级。

卡片翻面闪卡光效小队切换数据更新

成长中心既是小队档案，也是后续家长报告和机构续费的证据资产。

15 教师设置页：老师控制台

课程外老师使用验证码保护
进入前：乘法/除法验证码
快捷设置：阶段提示、课堂辅助、流程控制
课程阶段鼓励文案编辑

必要组件

  • 验证码门禁：防止小朋友误入。
  • 阶段提示编辑：课程环节间的 POKI 鼓励可修改。
  • 课堂控制项：可作为后续 BrainAgent 自主流程控制入口。
  • 页面视觉更偏成人工具，不做太游戏化。

验证弹窗设置卡展开保存 toast

教师设置必须和孩子上课界面分离，避免误触和认知干扰。

关键动效清单

页面跳转

非课程页面跳转使用中心 POKI toast，2-3s。课程环节之间不用这个，保留阶段提醒弹窗。

阶段提醒

课程环节切换时出现简单文字 + POKI 鼓励，默认 3s 自动关闭，可在教师设置中修改。

星星奖励

环节完成后星星在屏幕中央摇晃，3s 后或点击后沿弧线飞入收集卡罐子，飞行过程中逐渐缩小。

右侧信息栏

从右滑入，主容器保留完整边框。内容按 POKI 语音逐条出现。

视频画框

见面环节识别后等比例缩小到左侧；欢迎页视频先暂停首帧，POKI 说完再播放。

验证码门禁

出现时全屏遮罩，页面其它按钮不可点击。答错给短提示，不进入目标页面。
