01 / 当前结论

这版 UI 要解决什么

POKI 不是一个给成人读文字的工具，而是低龄儿童上课时会“看、听、跟着做”的课堂伙伴。设计重点不是把功能堆满，而是让孩子知道现在该做什么，让老师知道哪里能兜底。

孩子侧一屏一个任务

每个页面只保留一个主动作，避免孩子懵住。

老师侧入口少但清楚

老师要能快速切小队、测设备、退出课程、调试流程。

课堂侧自动推进优先

系统承担流程组织，老师只处理确认和异常。

视觉侧大图像 + 小文字

图像、视频、IP 动作优先，文字只做辅助理解。

动效侧柔和但明确

转场、奖励、角色说话要让孩子感知到变化。

适配侧统一 4:3 主画布

所有 UI 必须在主容器内，不能飘到浏览器边缘。

03 / 全局视觉规范

统一风格口径

当前产品面向 4-6 岁儿童，但使用者还包括机构老师。UI 不能太幼稚，也不能像成人后台。建议定位为“儿童课堂里的智能玩学系统”。

项目设计要求原因
画布比例所有核心页面包进居中的 4:3 主画布，主画布外只做浏览器背景。当前上课设备接近 Pad 场景，UI 需要统一设计分辨率，不跟 16:9 浏览器乱跑。
主容器课程内使用一个占视觉主体的大圆角容器；底部状态栏、顶部栏都必须独立，不互相遮挡。解决之前容器和进度栏重叠的问题。
颜色使用明亮但不刺眼的多色系统：天空蓝、草地绿、珊瑚粉、星星黄、少量紫色。避免单一紫色或成人化深色，增强儿童识别。
文字标题短，说明短；儿童主界面尽量用图标、图片、视频、IP 话语承担理解。4-6 岁儿童不稳定识字，不能依赖长文字。
IPPOKI 现阶段可用机器人 icon/emoji 占位，正式设计需要 1:2 身材 IP。统一课程陪伴感，替代散乱 emoji。
图像课程任务、积木、奖励、活动入口都优先使用图片/图形，不用大段文字标签。儿童更容易通过图像理解任务。
按钮孩子可点按钮要大、圆、少；老师按钮可更克制，但必须清楚可点。避免误触和视觉噪音。
教师安全设置、小队切换、兑换等老师操作使用算术验证弹窗。避免孩子误入教师功能或误兑换。

见面识别环节

视频流大容器先占据主视觉；识别完成后缩小到左侧，右侧信息栏同时出现。

课程内视频识别

视觉要求

问答1 / 问答2

两个问答环节逻辑一致，但目的不同：问答1理解视频问题，问答2理解固定拼搭作品和故事。

课程内三段式问答

  • 第一段：POKI 简单介绍问题，配图片或视频截图。

06 / 组件拆解

设计稿必须单独出组件状态

AppShell

4:3主画布

居中显示，所有顶部栏、底部栏、页面内容都在里面。外层只做背景。

AppChrome

顶部栏

左侧返回/退出，中间标题居中，右侧当前小队、宝石、齿轮设置。不能被右侧栏挤歪。

BottomNav

底部导航

课程外页面使用，加入 emoji/icon 提示，更可爱，但不占课程内容高度。

LessonStatusBar

课程状态栏

阶段描述、流程线、XP、星星罐子。和上方主容器保持明确间距，不重叠。

PrevNextControl

上一步/下一步

独立容器放在底部两端，不塞进状态栏容器。第一环节点上一步要弹退出确认。

MainStageContainer

课程大容器

课程内主视觉容器，大圆角，承载视频、任务图、积木泡泡、作品展示。

POKISidePanel

右侧信息栏

按需滑入，只显示自身大小；不能覆盖大容器顶部边框效果。

ActivityBubbleRail

活动悬浮球

首页右侧集中排列，支持收起，点击打开外部页面。

TeacherGate

算术验证弹窗

保护教师入口、兑换、小队切换。题目可用乘除法，避免儿童误入。

TransitionToast

非课程转场

“POKI 正在带你过去”只用于非课程页面跳转。课程内不使用这个通用 loading。

StagePrompt

课程阶段提醒

课程节点间使用简单文字 + POKI 鼓励，默认 3s 自动消失，可在教师设置中配置。

RewardCollector

星星/宝石收集

星星摇晃后平滑弧线飞入收集卡罐子，宝石从宝箱飞入账户。

07 / 动效规范

动效不是装饰，是流程提示

场景动效要求时间建议
非课程页面跳转中心 toast，POKI icon + “正在带你过去”，背景遮罩禁止点击其它按钮。2-3s
课程阶段切换使用阶段提醒弹窗，不使用通用 loading；默认自动关闭。3s
见面识别视频画框从全尺寸平滑缩小到左侧，右侧信息栏同时滑入。约5s节奏
POKI说话POKI 先说，再逐步展示对应信息卡。说到 1 号，显示 1 号卡。跟随语音
积木泡泡泡泡轻微上下漂浮；戳破时有缩放、粒子或弹出反馈。即时反馈
星星奖励星星先左右摇晃，3s 后自动沿平滑弧线飞向收集卡里的罐子，同时逐渐缩小；允许手动点击提前收集。3s等待 + 0.8s飞入
宝石奖励点击宝箱后，多个宝石从宝箱飞向右上角账户。0.8-1.2s
回首页倒计时按钮内倒计时变化，不另开一个大弹窗。15s
08 / 素材交付

需要 UI 设计师补齐的视觉资产

需要补

  • POKI 正式 IP：站立、说话、开心、思考、鼓励、等待、奖励动作。
  • 课程首页节点：解锁、未解锁、当前推荐、完成状态。
  • 活动小球图标：线下活动、产品理念、风采展馆、商业化入口。
  • 积木泡泡：不同颜色、数量、戳破状态。
  • 纪念卡、闪卡、星星罐子、宝箱、宝石飞行动效素材。
  • 课程环节背景：视频画框、任务图框、作品展示框。

不要做

  • 不要用大量文字标签替代图像。
  • 不要把活动入口设计成底部导航的复制。
  • 不要让顶部栏、底部栏飘出 4:3 主画布。
  • 不要把课程内每个阶段都做成通用 loading。
  • 不要让右侧信息栏外面再出现一个大空容器。
  • 不要让奖励飞向错误的罐子或账户位置。
09 / UI验收标准

设计完成后怎么判断可用

  • 所有页面都在 4:3 主画布内，顶部、底部、按钮、视频不飘出容器。
  • 课程内主容器和底部状态栏之间有明显间隔，不互相遮挡。
  • 首页第一眼看到的是课程地图，而不是活动卡片或营销功能。
  • 右侧活动小球能收起，点击后外部打开，不破坏当前原型页。
  • 登录后必须先选小队，不能默认进入 1 号小队。
  • 设置页只有设备测试相关内容，两个测试都点过后才能完成。
  • 见面环节的视频缩放、右侧信息栏、编号卡片出现顺序清楚。
  • 目标、介绍、问答都以 POKI 语音和图像为主，文字明显减少。
  • 找积木是一种积木一组泡泡，不再一次展示所有积木。
  • 成长卡奖励流程清楚：卡片、宝箱、宝石、回首页倒计时。
